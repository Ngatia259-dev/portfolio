Group Capstone Project

Community Hub Platform

A real-world platform built to give Kenyan communities a direct line to action — developed collaboratively over the final weeks of the program.

👥 Group Project (4 developers) 🗓️ 3-Week Sprint 🇰🇪 Built for Kenya 🚀 Full-Stack
The Problem We Solved

Kenyan communities lack a centralized, accessible channel to report and track neighborhood issues. Reports sent through informal channels (WhatsApp, phone calls) rarely reach the right authorities and almost never get tracked or resolved.

  • Theft & insecurity incidents
  • Power outages affecting entire estates
  • Flash flooding and drainage failures
  • Damaged roads and infrastructure
  • Other community challenges needing visibility
My Contributions
  • Designed and built the incident report submission form with client-side validation
  • Developed the Express.js REST API endpoints for creating and fetching reports
  • Integrated the MongoDB schema using Mongoose with proper data modeling
  • Built the responsive report card UI components using CSS Grid
  • Managed Git branching strategy and led code review for front-end PRs
  • Deployed the application to a cloud hosting environment
Technologies Used
HTML5 CSS3 Vanilla JS Node.js Express.js MongoDB Mongoose REST API Git GitHub Cloud Deploy
🌍
Real-World Impact Statement The platform demonstrates how technology can bridge the gap between citizens and decision-makers. By creating a transparent, searchable record of community issues, it gives local authorities data they can act on — and gives residents proof that their reports exist.
